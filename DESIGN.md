# DW Tech design system

## North star

DW Tech should feel like a precise technology partner with Desert Whales' imagination: strategic, engineered, and globally fluent. The memorable signature is a glass-whale form that turns the brand name into an ownable technology object.

## Palette

- Midnight purple: `#1A0046`
- Electric orchid: `#B063FF`
- Cobalt: `#214AE7`
- Ink: `#111111`
- Night: `#05040E`
- True white: `#FFFFFF`
- Mist: `#F5F3FA`

## Typography

Neue Montreal is the brand typeface. The implementation uses a resilient Neue Montreal / Helvetica Neue / Arial stack. Display text is close-set and large; body text stays generous and readable; utility text uses uppercase tracking only for factual labels.

## Layout and components

- 12-column desktop grid with a 1200–1320px content frame.
- Open section bands and hairline dividers; cards appear only for expandable service detail.
- Buttons use 10px corners, not fully rounded pills.
- Signature imagery sits in one restrained bordered frame with edge fades—never a colored overlay.
- Motion is limited to reveal transitions, service expansion, and the ambient hero object; reduced motion disables all nonessential movement.

## Accessibility

WCAG 2.2 AA contrast, semantic landmarks, visible focus, 44px minimum action targets, keyboard-operable navigation and service details, stable media geometry, and responsive reflow without horizontal scrolling.
